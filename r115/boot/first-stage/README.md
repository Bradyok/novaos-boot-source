# Retired: r115's first stage

This first stage (U-Boot TPL and SPL with three patches, TF-A BL31) was built and checked by its build's own gates in
r115, and never ran on a scope. It is retired: do not write it to a card. The current first stage is in
[`/development/rk3399-first-stage/`](../../../development/rk3399-first-stage/), and the repository's front page says what each part is.

r115's U-Boot proper (`../uboot-proper/`) is the boot loader r115 shipped.
